# 김씨 아재 · Avatar Studio

최종 확정 원본 PNG를 표시하는 마이크 반응형 2D 방송 아바타입니다. 웹캠·얼굴 추적·3D 기능·외부 오디오 API를 사용하지 않습니다.

## 설치 없이 브라우저 테스트

- 일반 화면: https://klvrandol.github.io/kim-ajae-avatar/
- 투명 화면: https://klvrandol.github.io/kim-ajae-avatar/?overlay=1

GitHub Pages 설정은 `main` 브랜치의 `/docs`입니다. Pages가 활성화되어 배포가 완료되어야 주소가 열립니다. 마이크 켜기 → 권한 허용 → 입력 장치 선택 후 말하세요. 작은 생활 소음은 게이트로 억제하고, 민감도와 입 움직임 강도를 조절할 수 있습니다. 마이크 없이 ‘입 움직임 테스트’로 3단계 입을 확인할 수 있습니다.

브라우저가 마이크를 차단하면 주소창 사이트 설정에서 허용하세요. HTTPS 또는 localhost가 필요합니다. 마이크 오디오는 녹음·전송·저장하지 않습니다.

## 확정 원본과 그림 보존

새 기본 자세는 책상 앞에서 키보드와 마우스를 잡고 앉은 모습입니다. 업로드된 `kim-ajae-seated-original.png.png`를 루트에 그대로 보존하며, `public/assets/kim-ajae-seated-original.png`와 `docs/assets/kim-ajae-seated-original.png`는 바이트까지 동일한 복사본입니다 (1086×1448 RGBA). 이중 확장자는 업로드된 파일명 그대로 보존했습니다.

이전 팔짱 원본과 `kim-ajae-original.png`는 얼굴 보정 텍스처의 출처 및 보관용으로 남겨두며, 기본 자세로 렌더링하지 않습니다.

기존 초록 츄리닝 SVG는 더 이상 사용하지 않습니다. 기본 무표정은 원본 PNG를 Canvas 2D로 그대로 표시합니다. 검정 뿔테안경·대머리 윤곽·코·수염 외곽·회색 츄리닝·앉은 몸통·손·키보드·마우스·책상은 원본 픽셀을 유지합니다. 투명 채널도 그대로 유지하며 흰색/검정색 배경을 입히지 않습니다. 종횡비를 고정해 얼굴이 늘어나지 않습니다.

입·눈·눈썹 변경은 기존 원본 기반 보정 이미지의 작은 영역만 가져와 가장자리를 부드럽게 합성합니다. 새 앉은 자세의 얼굴에 맞춰 눈·눈썹·입 각각의 크기, 기울기, 위치를 정합한 행렬은 `public/avatar.js`의 `seatedFaceRegistration`에 있습니다. 이 변환은 얼굴 패치에만 적용되며 몸통과 손·책상 소품에는 적용하지 않습니다. 보정 이미지는 원본 그 자체가 아닌 **파생 그림**입니다. 전체 보정 이미지를 캐릭터 본체로 교체하지 않습니다. 수염이 있는 턱이나 안경 전체를 변형하지 않습니다. 입 닫힘은 선택 표정의 입, 조금 열림/크게 열림은 보정된 입 텍스처를 사용합니다. 작은 입은 입 패치만 세로 압축합니다.

## 기능

- 마이크 장치 선택, 권한 요청, 켜기/끄기, 레벨 미터
- RMS 평활화, 노이즈 게이트, 3단계 입, 히스테리시스와 유지 시간으로 떨림 억제
- 원본을 기준으로 한 눈 감김 패치, 3.3–6.8초 간격의 짧은 자동 깜빡임
- 1px 수준의 미세한 호흡. 안경과 얼굴 파츠는 함께 고정되어 움직임
- 표정 8종: 기본 무표정, 피식 웃음, 크게 웃음, 화남, 당황, 어이없음, 집중, 한숨 (1–8)
- 크게 웃음은 웃는 눈과 활짝 열린 입을 유지하는 표정 프리셋입니다. 이 표정에서는 마이크 음량으로 입을 덮어쓰지 않습니다. 그 외 표정은 마이크 입력에 따라 입이 움직입니다.
- 표정 버튼, 마이크 설정, 민감도/강도 로컬 저장, 모바일 레이아웃
- 연결이 끊기거나 조작 패널을 닫으면 입 닫힘
- **키보드 슬램 버튼 / Q**: 업로드한 PNG를 1.2초 표시한 뒤 기본 자세로 복귀. 나머지 리액션 4개는 추가 자산이 없어 비활성화

단축키는 조작 중인 화면에 포커스가 있어야 합니다. 장치 선택·슬라이더 등 입력 요소에 포커스가 있으면 단축키를 무시합니다. 전역 단축키와 항상 위 표시는 제공하지 않습니다. 조작 패널에서 동시에 마이크를 켜는 것은 한 개만 권장합니다.

## OBS 사용과 검증 범위

OBS 브라우저 소스는 800×800을 권장합니다. 공통 1448×1448 투명 캔버스에 세로형 기본 자세와 가로형 슬램 이미지를 배치합니다. 기본 자세의 표시 크기와 비율은 유지하며 좌우 투명 여백을 슬램에서 활용합니다. `?overlay=1`에서 조작 숨기기를 눌러 캐릭터만 캡처하세요. H 키로 조작을 복원할 수 있습니다.

Pages 정적 모드는 동일 브라우저 프로필의 탭/팝업끼리 BroadcastChannel로 상태를 공유합니다. 일반 Chrome 패널과 OBS 브라우저 소스는 별도 환경이므로 서로 직접 동기화되지 않습니다. OBS ‘상호작용’에서 투명 화면의 마이크 버튼으로 권한을 허용해야 합니다. **OBS 버전에 따라 마이크 입력/권한이 지원되지 않을 수 있으며, 실제 OBS와 실물 마이크 검증을 완료했다고 보장하지 않습니다.** 브라우저의 가상 마이크 검증과 실제 방송 장치 검증은 다릅니다.

OBS에서 마이크 권한이 불가능하면 아래의 기존 Node 서버 모드를 방송 PC에서 실행하세요. 이 모드에서는 일반 Chrome 패널이 마이크를 분석하고 서버가 OBS 화면으로 입·표정 상태를 전달합니다. 일반 창 캡처 자체는 투명도를 보장하지 않습니다.

## 기존 로컬 서버 모드

Node.js 22 이상이 있는 방송 PC에서 (런타임 의존성 설치 불필요):

```sh
npm start
```

Chrome/Edge: `http://localhost:5173`, OBS: `http://localhost:5173/avatar`. 패널은 열어 두세요. 서버는 기본 5173 포트이며 `PORT` 환경 변수로 변경할 수 있습니다. `npm run dev`는 서버 변경 감시 모드입니다. 인증 없는 개발용 서버이므로 공용 인터넷에 직접 공개하지 마세요.

## 파일과 빌드

- `public/avatar.js`: 원본 이미지 기반 Canvas 합성, 얼굴 마스크 좌표, 표정, 깜빡임
- `public/assets/`: 원본 복사본과 얼굴 보정 텍스처. `README.md`에 출처·추가 파츠 요구사항
- `public/audio.js`: 음량 분석 결과의 입 단계 계산 및 떨림 억제
- `public/app.js`: 마이크·UI·키보드·서버/정적 모드 동기화
- `server.js`: 기존 HTTP/SSE 서버와 PNG 자산 제공
- `scripts/build-pages.js`: public과 자산을 `/docs`에 복사하고 정적 모드 활성화
- `tests/`: 서버·음량·정적 파일 일치·원본 해시 보존 검증

```sh
npm run build:pages
npm test
```

`public/`이 원본 코드이며 `docs/`는 Pages 배포 산출물입니다. 둘을 함께 커밋/푸시하세요. 자산 경로는 모듈 URL 기준 상대 경로여서 `/kim-ajae-avatar/` 아래에서도 동작합니다. `.nojekyll`을 포함합니다. 기존 Pages 설정을 변경할 필요는 없습니다.

## 필요한 추가 원본 자산

키보드 슬램은 업로드된 전체 PNG로 구현했습니다. 나머지 특수 리액션을 원본 품질로 구현하려면 다음의 투명 PNG 또는 PSD 레이어가 필요합니다.

1. 책상 위 손과 팔을 제거한 깨끗한 회색 츄리닝 몸통·책상 배경 (가려졌던 부분 복원)
2. 분리된 왼팔/오른팔과 손, 어깨/손목 기준점
3. 커피컵과 컵을 쥐고 입으로 가져가는 손/팔
4. 게임패드와 양손 그립
5. 환호하는 양팔/손
6. 얼굴을 가리는 손/팔

원본과 같은 선·피부 명암·츄리닝 삼선·좌표계를 유지해야 합니다. 향후 손으로 다듬은 표정별 눈·입·눈썹 파츠를 받으면 현재의 보정 텍스처만 교체할 수 있습니다. 기본 이미지는 그대로 유지됩니다.

## 키보드 슬램 리액션

`kim-ajae-keyboard-slam.png` 원본을 변경 없이 보존하고 `public/assets/`와 `docs/assets/`에 복사했습니다. 버튼 또는 Q로 실행하면 원본 슬램 이미지 전체를 1200ms 표시합니다. 이미지의 가로세로 비율을 유지하고 기본 자세와 공통 프레임을 사용합니다. 크기는 1.05배, 책상 하단은 y=1400에 맞췄습니다. 새로운 그림이나 추가 충격 효과는 만들지 않았습니다.

슬램 중에는 눈 깜빡임·입 합성·표정 전환을 중단하고 표정 버튼을 잠시 비활성화합니다. 마이크 분석은 계속하며 종료 즉시 기존 표정과 현재 음량의 입 움직임을 복구합니다. Q를 다시 누르면 1.2초를 새로 시작합니다. 동일한 마이크 상태 전달은 시간을 연장하지 않고, 만료된 리액션은 페이지를 다시 열어도 재실행하지 않습니다. 투명 화면에서도 동일합니다. 리액션 이미지는 기울어진 동작 자세이므로 원본에 그려진 머리·손 위치 자체는 기본 자세와 다릅니다.
