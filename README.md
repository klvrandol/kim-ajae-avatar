# 김씨 아재 · Avatar Studio

웹캠 없이 마이크 음량으로 움직이는 가벼운 SVG 파츠형 2D 방송 아바타. 외부 API, 계정, 이미지 다운로드, 런타임 패키지가 필요하지 않습니다.

## 실행

Node.js 22 이상을 설치하고 이 저장소에서 실행합니다.

```sh
npm start
```

방송 PC의 Chrome/Edge에서 `http://localhost:5173`을 여세요. 마이크 켜기를 눌러 권한을 허용하고 입력 장치와 민감도를 선택합니다. 설치 명령 없이 실행됩니다. 개발 시 `npm run dev`, 자동 검증은 `npm test`입니다. 포트를 변경하려면 `PORT` 환경 변수를 사용하세요.

## OBS 연결

1. **방송 PC에서 프로그램을 실행**하고 조작 패널을 열어 둡니다.
2. OBS에서 소스 → 브라우저 추가 → URL `http://localhost:5173/avatar`를 입력합니다.
3. 크기는 800 × 800. 배경은 실제 투명이며 크로마키가 필요 없습니다. 기본 OBS 브라우저 소스 투명 CSS를 유지하세요.
4. 화면 모서리로 크기와 위치를 조절합니다. 마이크 입력은 조작 패널이 처리하며 OBS 화면은 상태만 받아 그립니다.
5. 패널 버튼으로 표정과 리액션을 바꾸세요. 브라우저 창과 OBS 브라우저 소스 사이에도 서버 SSE로 전달됩니다. 패널을 닫으면 입은 자동으로 닫힙니다.

클라우드 서버에서 확인할 때는 해당 서버의 접속 가능한 HTTPS 주소가 필요합니다. 원격 서버의 localhost는 방송 PC의 localhost와 다릅니다. 이 앱에는 사용자 인증이 없으므로 공용 인터넷에 직접 노출하지 마세요. 로컬 또는 신뢰할 수 있는 개발 환경에서 사용하세요. 화면의 ‘투명 화면 열기’는 패널 없는 창을 열지만 일반 브라우저의 항상 위 기능을 제공하지는 않습니다. OBS 사용을 권장합니다.

## 구현 기능

- 대머리, 둥근 안경, 수염, 초록 츄리닝의 상반신 아저씨 캐릭터
- 랜덤 눈 깜빡임, 가벼운 호흡과 몸 흔들림
- Web Audio RMS 분석, 노이즈 게이트, 평활화, 닫힘/조금/크게 3단계 입
- 마이크 선택/켜기/끄기, 민감도, 입 강도, 레벨 미터, 권한 오류 안내
- 표정 6개: 기본/웃음/화남/당황/어이없음/집중 (1–6)
- 리액션 5개: 키보드 슬램/커피/게임패드/만세/얼굴 가리기 (Q/W/E/R/T)
- 1.8초 후 리액션 종료, 선택했던 표정 유지, 반복 실행 가능
- 마이크 없이 입 모양을 확인하는 테스트 버튼
- 조작 패널과 복수 OBS 화면 실시간 동기화, 연결 끊김 시 입 닫힘
- 민감도/강도 로컬 저장, 반응형 UI, 키보드 포커스 표시

단축키는 **조작 패널에 포커스가 있을 때만** 작동합니다. 입력 장치/슬라이더/버튼에 포커스가 있으면 오작동 방지를 위해 단축키를 무시합니다. 전역 단축키와 방송 중 다른 앱에서의 조작은 아직 지원하지 않습니다. 마이크 데이터는 녹음·저장·재생하지 않습니다. 서버에는 음량과 입 단계만 전달합니다. 카메라 요청은 없습니다. 조작 패널은 한 개만 사용하세요. 여러 패널에서 마이크를 동시에 켜면 마지막 입력 상태가 적용됩니다.

## 파일 및 확장

- `server.js`: 의존성 없는 Node 정적 서버, 상태 API, SSE 동기화
- `public/index.html`, `public/style.css`: 한국어 조작 패널과 투명 화면 스타일
- `public/avatar.js`: 캐릭터 SVG와 표정/동작. `head`, `body`, `eyes`, `brows`, `mouth`, `glasses`, `arm-left/right`, `prop-*` 그룹으로 분리
- `public/audio.js`: 음량 → 입 단계 계산
- `public/app.js`: 마이크 수명 관리, 장치, 단축키, UI, 동기화
- `tests/app.test.js`: 음량 단계/노이즈 게이트, HTTP, SSE 전달, 유휴 복귀 검증

실제 캐릭터 시안이 제공되지 않아 코드로 그린 원본 SVG를 사용했습니다. 이미지 교체 시 800×800 좌표계를 맞춰 해당 SVG 그룹을 이미지 또는 새 벡터 파츠로 교체할 수 있습니다. 새 표정은 `expressionNames`와 눈썹/입 정의, 새 리액션은 `reactionNames`, 서버 허용 목록 및 CSS에 추가합니다.

## 한계 및 다음 단계

입은 음량 기반이며 음소/발음 추적이 아닙니다. 리액션은 간단한 파츠 애니메이션으로, 실제 일러스트 리깅이나 Live2D 수준은 아닙니다. 다음 개선은 전문 캐릭터 파츠 교체, 팔 관절 리깅, 사용자별 노이즈 보정, OBS WebSocket/Stream Deck 또는 Electron 기반 전역 단축키·항상 위 표시입니다. OS의 마이크 권한, 실제 장치와 OBS 합성 결과는 방송 PC에서 최종 확인해야 합니다.

## 설치 없는 GitHub Pages 테스트

기존 Node 서버와 별도로 `docs/`에 정적 테스트 사이트를 제공합니다. Node 서버나 패키지 설치 없이 HTTPS 페이지에서 마이크 권한을 허용해 테스트할 수 있습니다.

- 테스트 주소 (Pages 활성화 후): https://klvrandol.github.io/kim-ajae-avatar/
- 투명 화면: https://klvrandol.github.io/kim-ajae-avatar/?overlay=1
- 마이크 켜기 → 권한 허용 → 말하기. 입 움직임 테스트 버튼은 마이크 없이도 동작합니다.
- 표정 6개, 리액션 5개, 눈 깜빡임, 호흡, 입력 장치/민감도/입 강도는 동일합니다.

### 최초 배포 설정 (저장소 관리자)

GitHub 저장소 **Settings → Pages → Build and deployment**에서:

1. Source: **Deploy from a branch**
2. Branch: **main**, Folder: **/docs**
3. **Save** 클릭. GitHub의 Pages 배포가 완료되면 위 HTTPS 주소에 접속합니다.

이 방식은 사용자 Actions 워크플로 파일이 필요하지 않습니다. GitHub가 `docs/`의 정적 파일을 배포합니다. 이후 `docs/` 변경을 main에 푸시하면 자동 재배포됩니다. Pages 활성화 전에는 위 주소가 404일 수 있습니다.

### 수정 후 정적 파일 갱신

```sh
npm run build:pages
npm test
```

`public/`이 원본이고 `docs/`는 배포 산출물입니다. 빌드 결과도 함께 커밋하세요. 자산 경로는 `./` 상대 경로여서 `/kim-ajae-avatar/` 하위 경로에서 정상 동작합니다. `.nojekyll`로 Jekyll 처리를 생략합니다. 비밀 키나 서버 API는 사용하지 않습니다.

### 정적 모드 OBS 사용 차이

GitHub Pages에서는 서버 SSE 대신 BroadcastChannel로 **동일 브라우저 프로필의 탭/팝업끼리** 상태를 공유합니다. 일반 Chrome 패널과 OBS 브라우저 소스는 별도 프로세스이므로 직접 공유되지 않습니다.

OBS 브라우저 소스에 투명 화면 URL을 입력하고 800×800으로 설정하세요. ‘상호작용’에서 화면의 마이크 버튼으로 권한을 허용하고, 표정/리액션을 조작할 수 있습니다. ‘조작 숨기기’로 버튼을 숨기며 H 키로 복원합니다. 숨기기 전에는 조작 UI도 캡처됩니다. OBS 버전에 따라 브라우저 소스의 마이크 권한을 지원하지 않을 수 있습니다. 이 경우 브라우저에서 먼저 기능을 테스트하고 기존 Node 서버 모드를 사용하면 Chrome 패널의 마이크 상태를 OBS로 전달할 수 있습니다. 일반 브라우저 창의 윈도우 캡처는 투명도를 보장하지 않습니다.

마이크 분석은 기기 내부에서만 수행하며 오디오를 GitHub에 업로드하지 않습니다. 권한 거부 시 브라우저 주소창의 사이트 설정에서 마이크 사용을 허용하세요. 단축키는 해당 화면에 포커스가 있을 때 동작합니다.
